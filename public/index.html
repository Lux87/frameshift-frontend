Quick Start

Get a job submitted and downloaded in under 30 lines of code.

1. Configure the connection

Before anything works, fill in the four values on the Connection page and hit Save, then Test connection.

  1. Engine URL — the IAP-protected engine domain, e.g. https://audi-frameshift-engine.com.
  2. API Key — your fsk_... key issued by the engine operator.
  3. IAP Client ID — the OAuth client ID of the engine's IAP audience. Same for every frontend on this engine.
  4. Service Account Key — upload the JSON key file from the engine operator, or leave empty on Cloud Run to use Application Default Credentials.
How auth flows: your browser calls http://localhost:8080/api/.... The frontend's server adds two headers before forwarding to the engine: Authorization: Bearer <IAP ID token> (minted from the SA) and X-Api-Key: fsk_.... The browser never sees either credential.

2. Submit a job from the browser

Every endpoint below is exposed at /api/* on the frontend. Call them with plain fetch — no headers needed.

JavaScript · browser 
const form = new FormData();
form.append('mode', '2d');
form.append('product_image', productFile);
form.append('background_image', backgroundFile);
form.append('action_prompt', 'on a polished marble countertop');

const res = await fetch('/api/process', { method: 'POST', body: form });
const { job_id } = await res.json();
console.log('Submitted:', job_id);

3. Poll until it finishes

Jobs run asynchronously. /process returns 202 immediately — poll /api/jobs/:id every second or two until status flips to completed or failed.

JavaScript · browser 
async function waitForJob(jobId) {
  while (true) {
    const r = await fetch(`/api/jobs/${jobId}`);
    const job = await r.json();

    if (job.status === 'completed') return job;
    if (job.status === 'failed') throw new Error(job.error);

    console.log(`${job.progress || 0}% — ${job.current_step}`);
    await new Promise(r => setTimeout(r, 1500));
  }
}

4. Fetch the results

Once complete, job.result.downloads is a map of output name → URL. Or call /api/downloads/:jobId to get the same map without the full job record. URLs are already rewritten to /api/download/... so they work in the browser.

JavaScript · browser 
const job = await waitForJob(job_id);

for (const [name, url] of Object.entries(job.result.downloads)) {
  const img = document.createElement('img');
  img.src = url;
  img.alt = name;
  document.body.appendChild(img);
}

Full end-to-end example

Putting it all together — a single function that takes two File objects and returns the final image as a blob.

JavaScript · browser 
async function processImage(productFile, backgroundFile, prompt = '') {
  const form = new FormData();
  form.append('mode', '2d');
  form.append('product_image', productFile);
  form.append('background_image', backgroundFile);
  if (prompt) form.append('action_prompt', prompt);

  const submit = await fetch('/api/process', { method: 'POST', body: form });
  if (!submit.ok) throw new Error(`Submit failed: ${submit.status}`);
  const { job_id } = await submit.json();

  while (true) {
    const r = await fetch(`/api/jobs/${job_id}`);
    const job = await r.json();
    if (job.status === 'completed') {
      const finalUrl = job.result.downloads.final_image
                    || job.result.downloads.final
                    || Object.values(job.result.downloads)[0];
      return fetch(finalUrl).then(r => r.blob());
    }
    if (job.status === 'failed') throw new Error(job.error);
    await new Promise(r => setTimeout(r, 1500));
  }
}

const blob = await processImage(productFile, bgFile, 'cinematic lighting');
const url = URL.createObjectURL(blob);
window.open(url);

Calling the engine directly (no frontend proxy)

If you're integrating server-side in another language, skip this frontend entirely and call frameshift-local directly. You'll need to mint an IAP ID token yourself.

bash · curl 
IAP_TOKEN=$(gcloud auth print-identity-token \
  --audiences=$IAP_CLIENT_ID \
  --impersonate-service-account=$SA_EMAIL)

curl -s "$ENGINE_URL/process" \
  -H "Authorization: Bearer $IAP_TOKEN" \
  -H "X-Api-Key: $FRAMESHIFT_API_KEY" \
  -F "mode=2d" \
  -F "product_image=@./product.png" \
  -F "background_image=@./background.jpg" \
  -F "action_prompt=studio lighting"
Gotchas: IAP tokens expire after ~1 hour — refresh them. If your SA key is wrong, IAP returns a Google login HTML page, not JSON. If the X-Api-Key is missing or wrong, IAP passes but the engine returns 401.

Endpoints

Every engine route a frontend can call, with request and response shapes.

Two paths for every endpoint. Engine is the direct URL on frameshift-local (requires Authorization: Bearer <IAP token> + X-Api-Key: fsk_...). Proxy is the route this frontend exposes at http://localhost:8080/... — browser code calls that with no auth headers; the frontend server adds them.

Auth headers

HeaderRequired onValue
Authorization All engine endpoints (IAP gate) Bearer <Google ID token>, audience = IAP_CLIENT_ID
X-Api-Key All except /health fsk_... — scopes jobs to your tenant

GET /health

GET /health proxy: /api/health

Liveness probe and license snapshot. Does not require X-Api-Key — but IAP still gates it at the network layer.

Response 200

JSON 
{
  "status": "ok",
  "version": "dev",
  "active_jobs": 1,
  "queue_depth": 0,
  "max_concurrent": 4,
  "uptime": 1834,
  "license": { "org": "Audi", "credits": 8421, "active": true }
}

Example

JavaScript · via proxy 
const health = await fetch('/api/health').then(r => r.json());
if (health.status === 'ok') console.log(`${health.active_jobs} jobs running`);

POST /process

POST /process proxy: /api/process

Submit a full V2.1 pipeline job: preprocess → Gemini relight → wavelet detail transfer → post-process. Returns 202 immediately with a job_id; poll /jobs/:id until completion.

Request (multipart/form-data)

FieldTypeDescription
mode required text One of 2d, cgi, cgi-topview, overlay, lite, prompt, prompt-raw
product_image required file JPEG / PNG / WebP, ≤ 50 MB
background_image file Required unless mode is prompt or prompt-raw
detailing_mask file Optional mask for region-locked detail transfer
action_prompt text Freeform prompt — appended to scene description in most modes, used raw in prompt-raw

Response 202

JSON 
{
  "message": "Job submitted",
  "job_id": "job_1771234567890_abc123x",
  "status": "processing"
}

Example

JavaScript · via proxy 
const form = new FormData();
form.append('mode', '2d');
form.append('product_image', productFile);
form.append('background_image', bgFile);

const { job_id } = await fetch('/api/process', {
  method: 'POST',
  body: form,
}).then(r => r.json());

POST /detail-transfer

POST /detail-transfer proxy: none (call engine directly)

Runs only the wavelet color-match stage — no Gemini, no preprocessing, no cropping. Inputs must already be dimension-matched. Useful when you generated the relight image elsewhere and just want texture recovery on the original product.

Request (multipart/form-data)

FieldTypeDescription
product_image requiredfileOriginal product image
relight_image requiredfilePre-generated relight output; must match product_image dimensions

Response 202

Same shape as /process.

Example

bash · curl direct 
curl -s "$ENGINE_URL/detail-transfer" \
  -H "Authorization: Bearer $IAP_TOKEN" \
  -H "X-Api-Key: $FRAMESHIFT_API_KEY" \
  -F "product_image=@./product.png" \
  -F "relight_image=@./ai-relight.png"

GET /jobs/:id

GET /jobs/{jobId} proxy: /api/jobs/{jobId}

Get the full record for a single job. While in flight, progress and current_step update. Once status is completed, result.downloads is populated with URLs you can fetch.

Response 200 — in flight

JSON 
{
  "job_id": "job_1771234567890_abc123x",
  "status": "processing",
  "progress": 55,
  "current_step": "wavelet",
  "input": {
    "product": "product.png",
    "background": "background.jpg",
    "mode": "2d"
  }
}

Response 200 — completed

JSON 
{
  "job_id": "job_1771234567890_abc123x",
  "status": "completed",
  "progress": 100,
  "duration_seconds": 45,
  "result": {
    "mode": "2d",
    "outputs": {
      "final": "/abs/path/final.png",
      "base": "/abs/path/base.png"
    },
    "downloads": {
      "final": "/download/job_177.../final.png",
      "base":  "/download/job_177.../base.png"
    }
  }
}

GET /jobs/history

GET /jobs/history proxy: none (call engine directly)

Pull your org's job history from the central license service. Survives engine instance restarts (the engine's in-memory job store is transient).

Query parameters

NameDefaultDescription
limit100Max records to return

Response 200

JSON 
[
  {
    "jobId": "job_1771234567890_abc123x",
    "status": "completed",
    "mode": "2d",
    "apiKeyId": "key_a1b2c3d4",
    "createdAt": "2026-04-23T14:12:03.118Z",
    "completedAt": "2026-04-23T14:12:48.902Z",
    "duration": 45,
    "error": null
  }
]
Note the camelCase keys — this endpoint is a passthrough from the central license service, so its shape differs from /jobs (which uses job_id, created_at, etc.).

Example

bash · curl direct 
curl -s "$ENGINE_URL/jobs/history?limit=20" \
  -H "Authorization: Bearer $IAP_TOKEN" \
  -H "X-Api-Key: $FRAMESHIFT_API_KEY"

GET /api/downloads/:jobId

GET /api/downloads/{jobId} proxy: /api/downloads/{jobId}

Convenience endpoint — returns just the download URL map for a completed job, without the full job record. The proxy rewrites the URLs to /api/download/... so they work directly in the browser.

Response 200

JSON — via proxy 
{
  "final": "/api/download/job_177.../final.png",
  "base":  "/api/download/job_177.../base.png"
}

Example

JavaScript · via proxy 
const urls = await fetch(`/api/downloads/${jobId}`).then(r => r.json());
for (const [name, url] of Object.entries(urls)) {
  const img = new Image();
  img.src = url;
  document.body.appendChild(img);
}

GET /download/:jobId/:filename

GET /download/{jobId}/{filename} proxy: /api/download/{jobId}/{filename}

Streams an actual output image. Served from local disk if the job is still on the engine instance, otherwise proxied from GCS. Content-Type is image/png.

Example — download to disk

bash · curl direct 
curl -s "$ENGINE_URL/download/$JOB_ID/final.png" \
  -H "Authorization: Bearer $IAP_TOKEN" \
  -H "X-Api-Key: $FRAMESHIFT_API_KEY" \
  -o final.png

Example — display in browser

HTML 
<img src="/api/download/job_177.../final.png" alt="Final">
